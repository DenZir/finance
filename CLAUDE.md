# CLAUDE.md

Указания для Claude Code в этом репозитории. Отвечать по-русски.

## Проект

**finance** («Деньги») — учёт денег владельца: доходы его Telegram-проектов
(приватка, реклама — посты и сторисы, заявки с приветки, партнёрка, VPN, прочее),
комиссии платёжек, кошельки в разных валютах, выводы и обмены, доля партнёра по
VPN. Отдельный сервис, а не раздел tg-analytics: деньги изолированы — своя база,
свой вход (Telegram Login, только `OWNER_TG_IDS`).

Node 22+/TypeScript (strict ESM, через tsx без сборки), Express 5,
better-sqlite3 без ORM, страница — чистый HTML/JS в `public/`.

Открытые задачи — в `.claude/BACKLOG.md`: сделанное отмечать, новое дописывать.

## Команды

```bash
npm run dev        # tsx watch src/index.ts (нужен .env)
npm test           # node --test, база в памяти
npm run typecheck  # tsc --noEmit
```

`npm run typecheck` и `npm test` — обязательные проверки перед каждым коммитом.
Новое поведение — с тестом в `tests/`. Изменения страницы проверяются в браузере
на десктопе и на 375 px.

## Устройство

- `src/money.ts` — суммы в целых «микро» (миллионных долях единицы). Деньги не
  хранятся и не складываются в плавающей точке.
- `src/db/migrations.ts` — схема; готовую миграцию не правят, только дописывают.
- `src/ledger.ts` — единственное место записи: операция и её проводки одной
  транзакцией. Баланс кошелька — сумма проводок, своего поля нет.
- `src/rates.ts` — курсы к рублю (CoinGecko + последний известный в базе).
- `src/auth.ts` — проверка подписи Telegram Login и сессии.
- `src/server.ts` — API и раздача `public/`.
- `src/import/botprivat.ts` — оплаты привата из ботприватa; `src/ads.ts` — сделки
  рекламы из tg-analytics (оплачено / ждём оплату / бартер); `src/vpn.ts` —
  оплаты VPN из tg-analytics на кошельки с ролью `vpn:platega` / `vpn:cryptobot`.
- `src/bot/` — бот входа он же бот учёта: запись строкой, /balance, /debts,
  напоминание о долгах. Bot API — через `fetch`, без библиотек.

Правила учёта: доход хранится до комиссии (`gross_rub`) и с комиссией
(`fee_rub`), на кошелёк ложится разница. Комиссия перевода — разница в рублях
между ушедшим и пришедшим. Выплата партнёру — не расход.
